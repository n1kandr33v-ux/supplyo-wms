# Ozon: каталог, остатки и сборка — 17.11.2026

Раздел «Остатки» получает полный каталог независимо от наличия заказов. Используются /v3/product/list, /v3/product/info/list и /v2/product/info/stocks-by-warehouse/fbs. Учитываются все SKU товара, включая разные FBO/FBS SKU. В таблице — баркоды, локальные код и адрес, доступное количество Ozon, резерв и отдельное количество на складе. Не полученная для выбранного FBS-склада запись обозначается «—», а не нулём; агрегированные FBO-остатки её не заменяют.

Каталог, количество и размещение хранятся в ozon_catalog, ozon_stock_levels, ozon_stock_placement. Обновление атомарно, ошибки сохраняют предыдущий снимок; 429 откладывает запросы. Каталог обновляется ежедневно или вручную, количество — по очереди синхронизации. Удаление товаров из каталога не удаляет историю внутренних остатков. Изменения размещения защищены версиями.

Внутренние остатки используют ozon:<основной SKU>. При отгрузке FBS SKU сопоставляется с основным; старые записи с точным FBS SKU сохраняют приоритет. Списание только при delivering/delivered, один раз на отправление. awaiting_deliver, сканирование и печать количество не уменьшают. Запись остатков в Ozon этим обновлением не выполняется: текущий ключ имеет Product read-only.

Баркоды и признаки маркировки распространяются на все SKU товара. Для сборки WMS КИЗ обязателен, если карточка товара имеет атрибут 23536=true либо отправление/экземпляр требует обязательной маркировки. Необязательная передача в Ozon не отменяет сбор КИЗ для явно маркированного товара. Один лишь possible без положительного признака карточки не принуждает к КИЗ. Отсутствующее свидетельство остаётся неизвестным. Сохранённый КИЗ проверяется по статусу перед завершением сборки. Архив владельца доступен без подписки и хранит коды 14 дней после сборки (см. OZON-MARK-RETENTION.md).

В сборке отображаются код и адрес выбранного склада. «Поставки» показывает FBS-отправления, по умолчанию ожидающие отгрузки, с печатью этикетки вместо прежней заглушки. Завершение сборки поддерживает одну упаковку; многокоробочные отправления требуют завершения в Ozon. Никакая реальная отгрузка или аппаратная печать при проверке не запускалась.

Проверки: серверные тесты ozon-inventory.test.ts — каталог/пагинация/алиасы/остатки/права/конфликт версий/сохранение снимка при ошибке/списание после отгрузки. Браузерный ozon-stocks-browser.cjs — каталог без заказов, редактирование кода/адреса/внутреннего количества и адаптивность. Регрессии: сборка Ozon, печать Ozon, scanner-next-item и scanner-focus WB. ## Автоматическая сборка и печать (18.11.2026)

В открытом разделе сборки браузер автоматически опрашивает `/ozon/assembly/auto-candidates` раз в 2 секунды. Кандидаты ограничены текущим пользователем (кто сканировал), магазином, складом, живыми правами assembly+supplies и активной подпиской/служебным доступом. Готовность вычисляется для полного отправления независимо от поиска/пагинации таблицы, каждый экземпляр учитывается один раз; положительный признак маркировки требует КИЗ. Готовые кандидаты имеют приоритет перед частично собранными.

Когда все экземпляры готовы, вызывается обычный защищённый finish: повторное чтение состава, КИЗ, их статусов и прав. Сохраняется ozon_ship_tasks; checking после обрыва не вызывает повторную сборку, worker сверяет Ozon. После awaiting_deliver запускается OzonPrintButton в autoStart: существующие сохранённые задания и квитанции предотвращают повторное печатание после обновления страницы; другой компьютер не забирает незавершённое задание. Автоматика не делает reprint=true. При ошибке агента доступен явный повтор. При формировании этикетки сохраняется ранее предусмотренная задержка Ozon 45 секунд после подтверждения сборки. Без открытого раздела сборки/подключённого печатного агента физическая печать не запустится; при возврате в раздел очередь восстанавливается. Списание внутренних количеств остаётся только при отгрузке, не при автоматическом завершении сборки.

Проверки: 37 серверных тестов; браузерная цепочка auto finish → подтверждение → этикетка → fixture printer → квитанция → reload без повтора; существующие сканер и ручная печать Ozon. Аппаратная печать в проверках не запускалась.
