# Счета по прайсу фулфилмента — 15 ноября 2026

В «Учёт → Счета» владелец фулфилмента открывает «Прайс услуг» и сохраняет свой список: название, единица измерения, цена в рублях. Прайс относится к аккаунту владельца, доступен только ему и общий для его складов. Другой ФФ имеет независимый прайс. Прайс по умолчанию пуст: пользователь пришлёт реальные услуги и цены позже; выдуманных ставок в production нет.

При нажатии «Создать счёт» услуги и цены подставляются из прайса. Пользователь указывает клиента и выполненные количества; дата и номер заполнены автоматически, номер можно изменить. Неиспользованные услуги остаются пустыми/нулевыми и не включаются в сохранённый счёт. Количество допускает до трёх десятичных знаков, цены — до двух. Каждая строка округляется до копеек, затем суммируются суммы строк. Общая сумма вручную не вводится.

В счёте сохраняются `invoiceItems` со снимком названия, единицы, цены и количества. Изменение/удаление услуги в прайсе не меняет старые счета. При редактировании старого счёта его прежние услуги сохраняют прежние цены; новые услуги добавляются из актуального прайса. Сервер проверяет итог и для новых строк сверяет цены с прайсом; устаревший прайс требует обновления. Счета без детализации, созданные до этой функции, сохраняют прежнюю форму и сумму.

Рядом со счётом есть кнопка скачивания Excel. Формируется настоящий `.xlsx`: клиент, склад, дата, номер, срок оплаты, услуги, единицы, количество, цена, сумма и итог. Числа остаются числовыми ячейками; суммы строк и итог содержат формулы и рассчитанные значения. Данные клиента/услуг записываются текстом, а не исполняемыми формулами. Экспорт старого счёта без строк показывает одну услугу на старую сумму. Для оплаченных счетов скачивание также доступно из связанной записи дохода. Формальные реквизиты исполнителя/НДС не выдумываются: это расчёт услуг, как запросил пользователь.

Существующая оплата счёта с приложением чека и добавлением дохода сохранена. Изменения прайса и учёта защищены серверными версиями; подписка и права проверяются при каждом запросе. `workspace_documents.kind='prices'`, собственный `user_id`; бухгалтерские записи остаются в существующем документе `accounting`.

Основные файлы: `src/components/invoice-services.tsx`, `src/components/accounting.tsx`, `src/live-workspace.tsx`, `src/lib/invoice.ts`, `src/lib/invoice-xlsx.ts`, `server/workspace.ts`. ZIP-контейнер XLSX создаётся браузерной зависимостью `fflate`; backend для генерации файла не вызывается.

Проверки: `server/invoices.test.ts` — независимые прайсы двух аккаунтов, версии, некорректные ставки/дубликаты, контроль суммы, снимки после изменения/удаления цен, старые счета и оплата, безопасный OOXML/формулы. `tests/browser/invoices.cjs` — создание прайса, счёта с дробным количеством, автоматический итог, изменение цены, скачивание реального XLSX, сохранность после перезагрузки и ширина 1024px. Скачанный файл дополнительно прочитан openpyxl в режиме проверки (без изменения): подтверждены числовые типы, формулы и рассчитанные суммы.


## 17 November 2026: client service presets
Each fulfillment owner can save a separate service-ID list for each client in the versioned `clientServices` workspace document. New invoices load that list when the client name matches (trimmed, whitespace normalized, case insensitive). Add/remove rows and explicitly save as permanent client services; quantities are never remembered. Current price list supplies rates; historical invoice snapshots are unchanged. Empty presets are supported. Owner isolation and stale versions are validated by server tests; browser test covers save/load, removal, adding back and quantity reset.
