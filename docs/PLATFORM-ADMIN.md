# Админ-панель платформы

Главный администратор задаётся точным адресом PLATFORM_ADMIN_EMAIL (на рабочем сервере it-mp@mail.ru). Аккаунт должен зарегистрироваться обычным способом с подтверждением почты. Совпадение домена само по себе прав не даёт. Главный администратор не удаляется через интерфейс.

Пункт «Админ-панель» находится в меню профиля. Доступ не зависит от платной подписки.

Права: users.read (пользователи), stores.read (кабинеты), orders.read (сохранённые WB/Ozon-заказы), fulfillments.read (фулфилменты и склады), subscriptions.manage (выдача/отзыв подписок; требует users.read), admins.manage (назначение/отзыв прав зарегистрированным пользователям), audit.read (журнал). Администратор может выдавать только имеющиеся у него права; не может менять собственные права, главного администратора или администратора с более широкими правами.

Просмотр фулфилмента фильтрует кабинеты владельца и делегированные кабинеты. Для делегированных заказов обязательно совпадение склада, а не только кабинета. Все списки имеют поиск/пагинацию по 50 записей. Заказы показываются из локально синхронизированной истории ВМС, без дополнительных запросов к маркетплейсам.

Подписка задаётся до конца выбранной даты по МСК и с лимитом кабинетов. Отзыв выставляет срок и лимит в ноль; данные пользователя не удаляются. Причина обязательна. Выдача прав и изменение подписок записываются транзакционно в platform_admin_audit с исполнителем, временем и предыдущими/новыми значениями. Отзыв прав действует на следующий запрос даже в открытой вкладке.

Пароли, ключи API, токены сессий, КИЗ и содержимое этикеток не выдаются административными списками. Обычные операции с заказами не получили обход существующей модели доступа.

Проверено server/admin.test.ts: анонимный и обычный доступ, ограниченные права, запрет повышения привилегий/удаления главного администратора, выдача/отзыв подписок и администраторов, журнал, фильтрация по складу, отсутствие секретов в ответах. Полный test:server: 46 тестов прошли.
