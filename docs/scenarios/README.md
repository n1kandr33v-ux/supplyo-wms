# Сценарии Supplyo

Согласованная целевая логика продукта. Это спецификация сценариев, а не подтверждение реализации серверных интеграций.

Актуальная схема сборки учитывает уточнение: стикер печатается сразу после скана КИЗ; готовность требует успешной печати и подтверждения КИЗ самим WB. Необходимость КИЗ определяется по API, без ручной галочки.

## Правила доступа и подписки

- Клиент может подключить магазин и выдать фулфилменту доступ без собственной подписки на ВМС.
- Одноразовый код определяет кабинет, маркетплейс и ровно один разрешённый склад.
- Без подписки рабочие разделы видны, но действия заблокированы; настройки и профиль доступны.
- В подписке показывается использованное количество кабинетов: «Добавлено X из N».
- Проверка формата КИЗ локально не заменяет подтверждение WB.
- Пока WB не ответил, товар с КИЗ не становится готовым, даже если стикер уже напечатан.
- Цены подписок, серверная авторизация, проверка API и оплата требуют отдельной реализации.
