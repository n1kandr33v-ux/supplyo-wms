# Режим Авто Ozon — 19.11.2026
На экране сборки рядом с подписью сканера добавлен переключатель Авто, по умолчанию выключен. Требуется конкретный склад. Один скан собирает все ожидающие экземпляры совпадающего товара без КИЗ на выбранном складе, с учётом фильтра номера отправления; поиск по таблице не ограничивает обработку.

Сервер повторно проверяет отправления и требования Ozon, товары с обязательным КИЗ не собирает пачкой. Если нет подходящих немаркированных экземпляров, остаётся обычный поштучный сценарий с запросом КИЗ. Готовые, занятые и проверяемые экземпляры пропускаются. Сохранение пачки атомарное; ozon_auto_scan_receipts хранит результат по requestId, пользователю и области, повтор не захватывает новые заказы. Ограничения: до 100 отправлений и 1000 экземпляров за запрос, при превышении нужно выбрать отправление. Ошибки API до фиксации не оставляют частично собранную пачку.

Существующая очередь завершает полностью готовые отправления и печатает этикетку после подтверждения Ozon. Для неё нужны права сборки/поставок, открытый экран и печатный агент. Незавершённые товары других артикулов не собираются автоматически. WB не изменён.

Проверено: 38 серверных тестов, сборка frontend, браузерный сценарий Ozon с переключателем и КИЗ, регрессия сканера WB. Без реальной сборки/печати в проверках.

Исправление 19.11: подтверждённые Ozon отправления остаются в сборке до отгрузки, с кнопками печати/повторной печати и отдельным признаком квитанции. «Собран» не равен физической печати. Очередь завершает следующие готовые отправления, пока предыдущая этикетка подготавливается или печатается; прежняя последовательная блокировка устранена. Одна упаковочная этикетка относится к отправлению, а не к каждой строке товара.
