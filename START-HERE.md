# supply — продолжение после переустановки Windows

Это существующий рабочий WMS, а не задание написать проект заново.

1. Клонировать `https://github.com/n1kandr33v-ux/supplyo-wms.git` в удобную папку.
2. Открыть папку в Codex. Передать текст из [PROMPT-FOR-NEW-CHAT.md](PROMPT-FOR-NEW-CHAT.md).
3. Агенту полностью прочитать [актуальный контекст](docs/HANDOFF-2026-11-18.md), [восстановление](docs/RESTORE-AFTER-WINDOWS.md), последние записи [DEPLOYMENT.md](DEPLOYMENT.md) и `git status`.
4. Для локальной разработки установить Git и Node.js 24, затем `npm ci` и `npm run start:live`. Адрес: http://127.0.0.1:8095.

Переустановка Windows не удаляет рабочий сервер. Не восстанавливать поверх него локальную базу, не переподключать магазины и не менять шифровальный ключ без отдельной необходимости.

Код, APK, EXE, схема и инструкции находятся в GitHub. Рабочая база, секреты и ключ подписи Android сохраняются отдельно в личном архиве восстановления. Архив должен находиться вне стираемого диска C, например на личном Яндекс Диске. GitHub не заменяет этот архив.
