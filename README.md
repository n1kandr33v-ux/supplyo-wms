# ЗакупИТ WMS v2

Вторая локальная версия интерфейса на React, TypeScript, Vite, Tailwind и shadcn/ui (Radix Nova).

Адрес: http://127.0.0.1:8093
Запуск из этой папки: npm run dev
Сборка: npm run build

Рабочая версия на 8088 не изменена. Здесь синтетические данные, сохранение в localStorage браузера, без подключения к WB и рабочей базе.

Экраны: обзор, новые заказы, поставки, сборка, остатки, настройки. Работают выбор кабинета и склада, поиск, создание тестовой поставки, отметки сборки, тестовая отгрузка со списанием, редактирование ячейки/адреса/количества, экспорт CSV. Сброс данных в настройках.

Основной интерфейс: src/App.tsx. Тема: src/index.css. Компоненты: src/components/ui.

Реальная печать, КИЗ, API маркетплейсов, авторизация и серверная база пока не подключены.
