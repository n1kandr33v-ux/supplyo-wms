# supply для Android — 0.2.0

Первая версия приложения для сборщика. Android 8.0 и новее, требуется интернет.

Сценарий: вход существующей почтой и паролем supply → доступные магазины → открытая поставка → товары для сборки. Права и состав магазинов проверяет существующий сервер. Карточка: адрес, код и количество крупно в одной строке; ниже баркоды. Название товара только в заметках. Двойной тап отмечает/снимает отметку на этом телефоне. Отметки сохраняются в localStorage отдельно по аккаунту, магазину и поставке, не меняют порядок карточек и не отправляются на сервер. Статусы сайта не влияют на локальную отметку. Свайп влево открывает заметки; их наличие показано маленькой карточкой справа снизу. Заметки общие для сотрудников с доступом к складу, хранятся в отдельной mobile_pick_notes; автор и время задаются сервером. Запись требует права сборки. Повторная отправка использует тот же id и не дублирует сообщение. Данные и заметки читаются раз в 15 секунд. Приложение больше не вызывает проверку КИЗ или получение стикеров на WB: только читает текущие данные сайта. Печать, КИЗ, готовность и отправка остаются независимыми.

APK — небольшая Android-оболочка с отдельным мобильным интерфейсом, загружаемым по HTTPS с текущего сервера supply. Интерфейс обновляется вместе с сервером. Нет встроенных паролей/API-ключей, доступа к файлам, камеры или JavaScript-моста. Сессия хранится в защищённой HttpOnly cookie WebView; при выходе сервер её отзывает. Навигация внутри приложения ограничена текущим HTTPS-хостом; ошибки сертификатов не обходятся.

Установка: скачайте `supply-android-0.2.0.apk` на Android, откройте файл и разрешите установку для браузера/файлового менеджера, если Android попросит. Это тестовая сборка с отдельной локальной подписью, не публикация Google Play. Для обновления поверх первой версии следует сохранять `.signing/preview.p12` и увеличивать versionCode.

## Сборка

Исходники Android: `app/src/main`. Стандартный Gradle-проект использует AGP 8.13, compileSdk/targetSdk 36, minSdk 26 и JDK 17. Можно открыть папку в Android Studio.

Для воспроизводимой сборки из корня WMS без IDE:

```powershell
python android-app/setup-tools.py
python android-app/build-apk.py
```

Скрипт загрузки размещает JDK 17 и официальные Android Platform 36 / Build Tools 36.0.0 в локальную игнорируемую `.android-tools`. Результат: `android-app/build/supply-android-0.2.0.apk`. Сборщик выполняет aapt2, javac, D8, zipalign, apksigner и проверяет подпись/manifest. Ключ тестовой подписи хранится только в игнорируемой `.signing`.

Мобильный интерфейс: `src/mobile.tsx`, `src/mobile.css`, вход через `?mobile=1#mobile`. Обычный сайт продолжает использовать свой интерфейс. Данные магазина и история не изменяются при открытии приложения.

## 0.3.0 — инвентаризация с телефона (24.11.2026)

versionCode 4, подпись сохранена от 0.2.1. Основной адрес приложения — https://supplyteam.ru; старый HTTPS-хост также разрешён для совместимости. После выбора магазина доступны «Сборка» и «Инвентаризация». WB и Ozon используют существующую серверную инвентаризацию, те же права склада и общий прогресс. В карточках показаны фактическое количество ВМС, код, адрес, баркоды и статус проверки. Сканирование камерой или ввод баркода открывает пересчёт. Повторный скан проверенного товара показывает сохранённое количество и время; новое сохранение требует явного выбора пересчёта. Неизвестный баркод не скрывает общий список. При сохранении передаётся исходная сессия, версии и устойчивый идентификатор операции; конфликты другого сотрудника/нового пересчёта отклоняются сервером. Обновление списка каждые 15 секунд, кроме открытой формы/сохранения. Экспорт Excel остаётся в веб-версии.

Камера использует локально поставляемый @zxing/browser (1D/2D), без передачи видео внешним сервисам. Запрашивается только видео, микрофон не используется. Поток останавливается после распознавания, закрытия и сворачивания. Android запрашивает CAMERA только при обращении страницы к камере, разрешает её только двум доверенным HTTPS-хостам supply. Доступ к файлам/JavaScript-мост не добавлены. Старый APK получает интерфейс и ручной ввод с сервера; для камеры необходим 0.3.0.

Проверено: check:server, build:live, test:server (46/46); сборка APK, manifest и подписи v2/v3, совпадение сертификата с 0.2.1, побайтовое совпадение опубликованного APK. В браузере на синтетических данных: начало пересчёта, баркод, изменение количества/адреса, общий список после сохранения, повторный скан, неизвестный баркод, сохранение прогресса после перезагрузки. Ширины 393 и 320 пикселей без горизонтального переполнения. Физическое сканирование камерой Android и установка обновления на устройство требуют проверки пользователем.

APK: public/downloads/supply-android-0.3.0.apk. Мобильный сайт: https://supplyteam.ru/?mobile=1#mobile.
