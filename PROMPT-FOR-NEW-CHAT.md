# Промпт для продолжения работы

Продолжаем существующий проект supply WMS из этого репозитория. Сначала прочитай START-HERE.md, docs/HANDOFF-2026-11-18.md и последние записи DEPLOYMENT.md. Не переписывай рабочий продукт с нуля. Сохраняй WB при доработках Ozon, историю, доступы и размещение товаров.

Основной сайт https://77-87-212-236.sslip.io/, PostgreSQL на VPS 77.87.212.236, systemd supplyo, /opt/supplyo/current. Последний известный release 20261118-ozon-auto-print-v1; перед изменениями проверь фактическое состояние. Node.js 24, npm ci, npm run start:live; проверки npm run check:server, npm run build:live, npm run test:server.

В проекте есть WB и Ozon FBS, сборка/КИЗ/этикетки/автопечать, отдельные внутренние и маркетплейсные остатки с подтверждаемой передачей, сотрудники и делегирование по складам, учёт и счета с прайсами каждого FF, постоянные услуги клиента, Excel, Android-приложение и Windows print agent. Актуальные правила подробно в handoff. Подписки пока тестовые. Неизвестные требования к КИЗ не считать доказательством отсутствия маркировки. В Ozon положительный атрибут 23536 требует КИЗ даже при optional передаче в самом отправлении; каждая штука собирается отдельно.

Рабочая БД, шифровальный ключ, API-токены и ключ подписи Android не включены в GitHub. Не печатай их в логах и не заменяй производственные данные локальной копией. Наличие закрытого архива восстановления в облаке не подтверждено: ранее эта задача отменялась. GitHub сохраняет код и публикуемые сборки, а не секреты и клиентские данные.

Новые задачи выполняй в текущем стиле интерфейса, с проверкой и публикацией, когда она авторизована. Физическая печать не доказывается mock-тестами. Сначала сообщи, что понял актуальное состояние, и продолжим с задачей пользователя.
